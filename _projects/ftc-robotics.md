## Overview

For two seasons, *Relic Recovery* (2017–18) and *Rover Ruckus* (2018–19), I was the sole
autonomous and programming lead for my high school's FIRST Tech Challenge team, responsible for
all of the robot's code: driver control and the autonomous routines that run
with no human input at the start of each match.

## Vision navigation

Navigation code from the *Relic Recovery* season. The robot's phone
tracks image targets on the field with Vuforia. I derived a correction that factors the
phone's rotation out of the measured position, which gives more accurate results when the camera
sits at an angle to the target.
