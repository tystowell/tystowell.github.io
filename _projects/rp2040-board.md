## Overview

A board built around the Raspberry Pi RP2040 microcontroller for industrial-style signal I/O.
The schematic is split into these subsystems:

- **0–10 V** analog input and output
- **Current-loop** (mA) analog input and output
- **Digital** inputs and outputs, and **PWM** outputs
- **Power** supply
